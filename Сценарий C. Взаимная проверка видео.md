# Сценарий C. Взаимная проверка видео

Для заданий с физической сборкой схем, которые невозможно проверить автоматически: аппаратный дребезг (1.2.3), подключение датчика и дисплея (модуль 4), итоговый проект (модуль 5).

## Принцип

Обучающийся снимает короткое видео (до 60 сек) или фото и загружает его на платформу. Задание засчитывается только после того, как **двое других обучающихся** посмотрели видео и поставили оценку по чек-листу критериев.

Система автоматически назначает проверяющих из числа тех, кто уже сдал это задание. В личном кабинете появляется раздел «Проверить работу коллеги».

Чтобы получить полный балл за задание с peer-проверкой, обучающийся обязан сам проверить не менее двух работ. Проверять больше можно, оценка от этого не вырастет.

## Анонимность

В интерфейсе проверки видны только: номер задания, видео/фото, чек-лист. Никаких имён, аватаров, ссылок на аккаунты. Платформа хранит связь «видео → автор» только во внутренней БД и не раскрывает её участникам.

## Антифрод

- Оценка засчитывается только если проверяющий провёл на странице не менее N секунд (длительность видео).
- При расхождении двух оценок назначается третий проверяющий — его оценка решающая.
- Систематически мгновенные оценки помечаются системой.

Критерии для каждого задания формулируют авторы курса.

**Правило зачёта:** CI passed И большинство peer-оценок = «зачёт».
