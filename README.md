# es-test

Автоматическая проверка заданий программы «Встраиваемые системы». Как работать с репозиторием — [AGENTS.md](AGENTS.md).

## Разделы

- [Сценарии проверки](Сценарии%20проверки.md) — контекст, четыре сценария A–D, итоговая сводка.
- [Сценарий A. CI и тест-агент](Сценарий%20A.%20CI%20и%20тест-агент.md) — GitHub Actions + локальный `pico-check`; распределение заданий по слоям.
- [Сценарий B. Облачный стенд](Сценарий%20B.%20Облачный%20стенд.md) — пул из 20 плат, идентификация прошивки, инфраструктура.
- [Сценарий C. Взаимная проверка видео](Сценарий%20C.%20Взаимная%20проверка%20видео.md) — peer-проверка, анонимность, антифрод.
- [Сценарий D. Конструктор спутника](Сценарий%20D.%20Конструктор%20спутника.md) — телеметрия по CAN через WebSocket, Grafana.
- [HMAC и токены](HMAC%20и%20токены.md) — `student_token`, `secret_key`, подпись отчётов.

Проверки разворачиваются из этих требований точечно: одна проверка — одно задание.
