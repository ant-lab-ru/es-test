# es-test

Автоматическая проверка заданий программы «Встраиваемые системы». Как работать с репозиторием — [AGENTS.md](AGENTS.md).

## Проверки

Тело проверок вызывается из репозитория обучающегося через `workflow_call`. Как это устроено и как добавить проверку — [Разработка проверок](Разработка%20проверок.md).

- [checks/](checks/) — скрипты проверок и общий отчёт `lib/report.sh`.
- [.github/workflows/](.github/workflows/) — вызываемые workflow курса.
- [.github/actions/pico-toolchain/](.github/actions/pico-toolchain/) — установка ARM GCC, Pico SDK и picotool.
- [student/.github/workflows/](student/.github/workflows/) — файлы, которые обучающийся копирует в свой репозиторий.
- [run-local.sh](run-local.sh) — локальный прогон тех же проверок.

Занятие 1.1 закрыто полностью: `1.1.1`–`1.1.4`.
