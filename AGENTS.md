# AGENTS.md

**es-test** — автоматическая проверка заданий программы «Встраиваемые системы» на основе GitHub Actions. Самодостаточен. Студенты знают, какие проверки существуют, но не видят их содержание.

## Правила

- Проверки точечные: одна проверка — одно задание; разворачиваются из технических требований.
- Код — по-английски, kebab-case; лаконичный и самоописываемый. Проза — по-русски, без жаргона.
- Написанное человеком неприкосновенно по словам; всё, что создаёт агент, явно помечается как синтетическое до утверждения человеком.
