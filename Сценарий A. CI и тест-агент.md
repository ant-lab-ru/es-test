# Сценарий A. CI и тест-агент

Основной сценарий — для обучающихся с личным комплектом. Два слоя: статическая проверка в GitHub Actions и локальный тест-агент на реальном железе.

## Слой 1 — статическая проверка через GitHub Actions

В начале курса обучающийся создаёт папку `.github/workflows/` в своём репозитории и копирует туда yml-файлы, которые выдаёт платформа. Fork не нужен — обычный репозиторий из задания 1.1.4.

Один yml на каждое задание. Каждый срабатывает только при изменении соответствующей папки:

```yaml
# .github/workflows/check_1_1_2.yml
on:
  push:
    paths: ['blink/**']
jobs:
  check:
    uses: ant-lab/pico-checks/.github/workflows/check_1_1_2.yml@main
```

Реальная логика проверки хранится в `ant-lab/pico-checks` и вызывается через `workflow_call` — обучающийся не видит тело проверки. Обновление логики в `ant-lab/pico-checks` немедленно распространяется на всех обучающихся.

| Тип проверки | Инструмент | Пример |
|---|---|---|
| Компилируется ли проект | cmake + make в Docker ARM toolchain | make без ошибок |
| Структура проекта | `test -f` в bash | наличие `main.c`, `CMakeLists.txt`, `.gitignore` |
| Наличие функций | grep по сигнатуре | `bool get_button_debounce(uint pin)` |
| Наличие команд | grep по строковому литералу | `"uptime"`, `"mem_info"`, `"fw_info"` |
| Подключение библиотек | grep по CMakeLists.txt | `hardware_dma`, `hardware_uart` |

Прогресс накапливается по мере push: в начале курса все задания красные, к концу — зелёные. Платформа читает статусы через GitHub API (GitHub App с правом `checks:read`).

## Слой 2 — локальный тест-агент

Применяется для заданий с реальным поведением устройства: команды через USB serial, измерения АЦП, работа периферии.

Курс поставляет Python-пакет `pico-check` (`pip install pico-check`). Агент автоматически находит COM-порт Pico:

```bash
pico-check test 2.1.2   # выполнить тест-сценарий
pico-check submit       # подписать результат и отправить на платформу
```

Пример теста для задания 2.1.2 — команда `info`:

```python
def test(port):
    pico = serial.Serial(port, 115200, timeout=2)
    pico.write(b"info\n")
    response = pico.read(256).decode()
    assert "name" in response.lower()
    assert "version" in response.lower()
```

Отчёт подписывается HMAC-SHA256 с secret_key обучающегося — см. [[HMAC и токены]].

**Правило зачёта:** CI passed И hmac OK И все checks pass.
