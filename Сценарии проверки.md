# Сценарии проверки

## Контекст

Обучающиеся пишут прошивки (встроенное программное обеспечение) для микроконтроллера Raspberry Pi Pico (RP2040) с реальным железом: датчик BME280, дисплей ILI9341. Проверка заданий должна быть автоматической и не требовать участия преподавателей.

Для репозиториев используется GitHub. GitHub Actions бесплатен на публичных репозиториях без ограничений — каждый обучающийся использует ресурсы своего аккаунта.

Базовые наборы оборудования предназначены для очных занятий; обучающиеся на дистанционном формате покупают набор самостоятельно.

## Четыре сценария

Обучающийся может их комбинировать — например, купил комплект, но задание 1.2.3 сдаёт через видео.

| Сценарий | Кто | Метод проверки |
|---|---|---|
| **[[Сценарий A. CI и тест-агент\|A]]** | Купил комплект (большинство) | Git CI + локальный тест-агент |
| **[[Сценарий B. Облачный стенд\|B]]** | Не купил комплект | Git CI + облачный стенд |
| **[[Сценарий C. Взаимная проверка видео\|C]]** | Задания с физической сборкой | Git CI + взаимная проверка видео |
| **[[Сценарий D. Конструктор спутника\|D]]** | Финальный проект | Git CI + телеметрия на конструктор спутника |

Подпись результатов и идентификация — [[HMAC и токены]].
